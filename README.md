## ⚡ About Me

<img align="right" width="340" src="https://user-images.githubusercontent.com/74038190/229223263-cf2e4b07-2615-4f87-9c38-e37600f8381a.gif" alt="Developer Coding Illustration" />

I am a **Java Backend Developer** and **Associate Software Engineer at Cognizant** based in **Chennai, India**, focused on architecting secure, scalable, and maintainable server-side applications with **Java (8/11/17) & Spring Boot**. I enjoy designing layered backend systems, crafting clean RESTful APIs, and supporting reliable inter-service communication.

- 🚀 **Backend & Microservices:** Developing RESTful microservices and modular backend modules using **Java 17**, **Spring Boot**, **Spring MVC**, **Spring Data JPA**, and **Hibernate**—focusing on clean API contracts, request validation, and centralized exception handling.
- 🛡️ **API Gateway, Security & Caching:** Implementing request routing and **Redis-based rate limiting** with **Spring Cloud Gateway**, alongside **JWT authentication** and **role-based access control (RBAC)** using **Spring Security**.
- 🗄️ **Databases & ACID Transactions:** Modeling relational schemas, writing optimized SQL joins and indexes, and managing ACID transactions across **MySQL** and **PostgreSQL**.
- 🐳 **Testing & Cloud Deployment:** Writing unit and integration tests with **JUnit 5 & Mockito**, documenting endpoints via **Swagger/OpenAPI**, and deploying containerized services with **Docker** on **AWS (EC2, RDS, S3)**.
- 🧠 **Algorithmic Problem Solving:** Solved **350+ Data Structures & Algorithms problems** across **LeetCode** and **GeeksforGeeks**.

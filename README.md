## 👨‍💻 About Me

<img align="right" width="340" src="https://user-images.githubusercontent.com/74038190/229223263-cf2e4b07-2615-4f87-9c38-e37600f8381a.gif" alt="Developer Coding Illustration" />

I am a **Java Backend Developer** based in **Bengaluru, India**, focused on designing clean, maintainable, and high-performance server-side applications using **Java & Spring Boot**. I enjoy turning complex business logic into well-structured RESTful APIs backed by reliable relational and NoSQL databases.

- 🚀 **Backend Development:** Building layered RESTful services with **Java**, **Spring Boot**, DTO-driven contracts, **Spring Data JPA / Hibernate**, and role-based security using **Spring Security**.
- 🗄️ **Database Engineering:** Designing normalized relational schemas and transactional workflows in **MySQL**, alongside flexible document models in **MongoDB**.
- 🐳 **Testing & Cloud DevOps:** Writing isolated integration tests with **Testcontainers & JUnit 5**, containerizing services with **Docker**, automating CI/CD via **GitHub Actions**, and deploying on **AWS EC2**.
- 🧠 **Algorithmic Problem Solving:** Practicing Data Structures & Algorithms consistently on **LeetCode** (`Trees`, `Graphs`, `Dynamic Programming`, `Top Interview 150`).
- ☁️ **Cloud Certified:** **Microsoft Certified: Azure Fundamentals (AZ-900)**.
